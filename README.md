# Nike Sales Analysis

## Project Overview

This project analyzes Nike sales data using Python and data analysis techniques.

The project focuses on exploring sales performance, products, regions, states, sales methods, and sales trends over time.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
